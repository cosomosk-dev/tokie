## 1. お金と出来事のつじつま

- [ ] 1-1 収入の種類と出来事が合う。家賃収入の人(誠一郎)に「賃上げ」を出さない(家賃の改定にする)。タカヒロの収入は実際どおりで固定(上がるのはあなたの給料だけ)。
- [ ] 1-2 物価は2026年固定。「値上げ」と「賃上げ(または家賃の改定)」は出来事として各1回ずつ。収入の種類に合うルートだけ。
- [ ] 1-3 家の格と費用が合う。お金持ちの家は子どもの教育費・習い事もそれなりにかかる。安すぎは不可。
- [ ] 1-4 家計簿は統計どおり(家計調査・子供の学習費調査・保育料・児童手当・J-FLEC)。平均的な家は手取りの1割強しか貯まらない。貯金がポンポン増えない。
- [ ] 1-5 思わぬ出費は現実の相場。夫のお小遣いは2〜3万円台が出る水準。
- [ ] 1-6 子ども2人で即赤字にならない(ふつうの家でも2人は育てられる)。
- [ ] 1-7 主人公の手取りは職業ごとの30代前半女性の統計どおり(公務員で手取り29万は多すぎ、看護師はもっと多い)。都市部/地方で差がある。
- [ ] 1-8 一時金で貯金が二重に増えない(選択時の+と家計簿の積み上げがかぶらない)。
- [ ] 1-9 男性育休は給付で給料がある程度出る(手取りの約8割、上限あり)。
- [ ] 1-10 開業資金・ローン・家の値段は現実の相場。
- [ ] 1-11 本文・千代子の中の数字(年収・家賃・残高・貯められる額)が、家計簿・結末の数字と合う。
- [ ] 1-12 夫の財産は小さく1行で、ふたりの貯金に足し込まない(タカヒロだけ「ふたりで豊かになった」見せ方)。
- [ ] 1-13 夫にも結婚前の貯金がある(J-FLEC 単身30代・保有世帯の中央値300万)。結婚の画面に「結婚前の夫の貯金」を出す。夫のものは内訳(株・ビルと預金)つきで、出来事で動く(車・頭金・株の値上がり)。
- [ ] 1-14 ふたりの貯金をマイナスのままにしない。足りない分は夫の結婚前の貯金→あなたの結婚前の貯金の順に出し、行で見せる(使い道が決まった貯金=蓮の独立資金は除く)。

## 2. 法律(行政書士の名前で出す。必ず正しく)

- [ ] 2-2 遺留分は兄弟姉妹には無く、子(孫の代襲を含む)には有る。
- [ ] 2-3 相続税の申告・納税は知ってから10か月。相続放棄は知ってから3か月・家庭裁判所。放棄は取り消せない。相続財産を処分すると放棄できない。

## 3. 日本語(一読で分かる)

- [ ] 3-1 一読で意味が通る。短く。長文は1文1行の形で、一瞬で読める。
- [ ] 3-2 選択肢だけ読んで意味が分かる(前の話を覚えていなくても)。文脈の分からない選択肢は不可(例: 誠一郎8話「『何もしなくていい』って言ったのは、あなただから」)。
- [ ] 3-3 比較なのか自分の変化なのか分からない書き方は不可(「あなたより深い」)。
- [ ] 3-4 見出しに反対の選択肢の全文を入れない(22字で切る)。
- [ ] 3-5 同じ言い回しの連発をしない(「耳まで赤い」など、1ルートの中で同じ照れ方を何度も使わない)。

## 4. 台詞・展開の自然さ

- [ ] 4-1 普通の女性が言わない台詞は不可(「年収300万で結婚って考えてる？」など)。女性が立ち飲み屋を提案するのも不可。
- [ ] 4-2 意味の通らない展開は不可。前の話と矛盾しない(年数・年齢・名前・子どもの有無・住まい)。
- [ ] 4-3 2話目でいきなり真剣交際・プロポーズは早い。相談所の流れ(仮交際→真剣交際→成婚退会)に沿う。
- [ ] 4-4 似た展開の使い回しをしない(親の事業を継ぐ、など)。夢の店が毎回同じにならない(職業×ルートで変える)。
- [ ] 4-5 小物はおしゃれに、女の子向けに(「味噌汁に合う酒」は不可)。
- [ ] 4-6 その職業の人には起きない出来事を出さない(職業で分ける)。
- [ ] 4-7 子どもの名前に、夫の名前の字を使わない(悠太の子を「悠」にしない)。
- [ ] 4-8 子どもの年齢と学年が、生まれた年と合う(結婚○年目に何歳か数える)。
- [ ] 4-9 伏線の小物(悠太の桐の箱など)は、誰が・なぜ・中身は何かを、明かす回で一文で言い切る。

## 5. 信頼・ときめき

- [ ] 5-1 信頼・ときめきが動くたびに理由1行。数字と理由が本文で起きたことと合う。
- [ ] 5-2 褒める・話を聞く選択で、ときめきが下がらない。
- [ ] 5-3 段階名は「まだ遠慮がち→本音で話せる→頼り合える→支え合える→一生の味方」(信頼)、ときめきはハート5個。※2026/11/01にタケオさんの指摘で「愛情→信頼」に変更済み。最初の案「出会ったばかり→恋人→新婚→家族→一生の人」は、ときめきと意味がかぶるため置き換えた。
